## Текущее состояние

Astoria уже пригодна для использования как dev-сборка, но это ещё не готовый и
не проверенный на всех устройствах релиз. Сейчас основное внимание уделяется
Windows и Android. Цели для iOS, macOS и Linux присутствуют, но проверяются реже.
Web не поддерживается.

Официальных публичных сборок **пока нет**. Сейчас приложение нужно собирать из
исходников по инструкции ниже. В будущем релизы появятся в репозитории
[Astoria-Project-Release](https://github.com/danvitv/Astoria-Project-Release/releases).

## Что уже работает

- **Ролевые чаты** — потоковая генерация, регенерация, свайпы вариантов,
  редактирование, ветвление, фоновая генерация и отдельная обработка рассуждений.
- **Персонажи и промпты** — карточки SillyTavern V2, пресеты, лорбуки, персоны,
  заметки автора, regex-скрипты и широкий набор макросов.
- **Контекст длинных сессий** — Memory Books, Summaries, Links и Studio Ledger
  помогают сохранять важные факты и состояние сцены. Изменения постоянной памяти,
  созданные моделью, проходят явную проверку там, где это необходимо.
- **Astoria Studio** — настраиваемая многоэтапная генерация со
  специализированными агентами, контроллерами, финальными авторами, каноном и
  инструментами сверки.
- **Astoria Assistant** — встроенное рабочее пространство поддержки с отдельным
  подключением модели, ограниченной диагностикой, навигацией по источникам,
  выбранными действиями над приложением и зашифрованным экспортом отчётов. Им уже
  можно пользоваться, но первоначальный план продукта и миграция учётных данных
  ещё не завершены.
- **Расширения (ExtBlocks)** — информационные блоки после генерации, генерация
  изображений, изолированный JavaScript и интерактивные HTML-панели с запретом
  возможностей по умолчанию.
- **Генерация изображений** — работа с провайдерами изображений внутри чата и
  сценариев расширений.
- **Темы и макеты** — светлая и тёмная темы, свои цвета, шрифты и фоны, отдельные
  интерфейсы для мобильных и настольных устройств.
- **Локальная статистика и хранение** — чаты, персонажи, пресеты и связанные
  данные приложения хранятся в локальной базе SQLite.
- **Опциональная синхронизация** — Dropbox и Google Drive могут переносить
  резервные копии между устройствами.

Совместимость практическая, а не абсолютная. Astoria импортирует и экспортирует
карточки SillyTavern V2 и поддерживает распространённые пресеты, лорбуки,
regex-скрипты и макросы, но не реализует каждую функцию SillyTavern один в один.

## Приватность и безопасность

Astoria следует принципу local-first, но не является полностью офлайн-приложением.
База и медиа остаются на устройстве, пока ты не используешь синхронизацию или
экспорт, однако промпты и выбранный контекст отправляются настроенному тобой
провайдеру модели. Провайдеры изображений также получают входные данные генерации.

Astoria Assistant читает данные приложения только после включения единого
разрешения. Его источники исключают данные авторизации, а экспорт отчёта требует
отдельного просмотра и подтверждения. Очистка старого хранения учётных данных ещё
не завершена, поэтому раннюю версию не следует считать продуктом, прошедшим аудит
безопасности.

Импортированные пресеты и расширения могут содержать регулярные выражения,
скрипты и интерактивный контент. Проверяй материалы из недоверенных источников
перед включением.

## Сборка из исходников

### Требования

- Flutter 3.44+ и Dart 3.12+
- Git
- Нативный инструментарий целевой платформы:
  - Visual Studio с компонентами C++ desktop для Windows
  - Android Studio / Android SDK для Android
  - Xcode для iOS и macOS
  - зависимости Flutter Linux desktop для Linux

### Настройка

```bash
git clone https://github.com/danvitv/Astoria-Project.git
cd Astoria-Project
flutter pub get
cp .env.example .env
flutter run -d windows # либо android, ios, macos, linux
```

Файл `.env` включён в набор ресурсов Flutter и должен существовать. Пустые
значения допустимы — вход через Dropbox и Google Drive просто будет недоступен.
Никогда не коммить заполненный `.env`.

### Проверки и сборки

```bash
flutter analyze
flutter test
flutter build windows
```

Сборка Android ARM64 release из Windows:

```powershell
.\scripts\build_android_arm64.ps1
```

После изменения моделей Drift, Freezed или JSON Serializable обнови
сгенерированный код:

```bash
dart run build_runner build
```

Подробности см. в документах о
[рабочем процессе](docs/WORKFLOW.md), [сборке](docs/BUILD_NOTES.md) и
[каналах релизов](docs/RELEASE_CHANNELS.md).

## Технологии

Astoria использует Flutter, Riverpod, Drift/SQLite, Dio, GoRouter и WebView для
рендеринга чата. Основные части исходников:

```text
lib/core/                 модели, база данных, провайдеры и общие сервисы
lib/features/chat/        чат, генерация и мост WebView
lib/features/studio/      многоэтапные сценарии Studio
lib/features/memory/      Memory Books и консолидация памяти
lib/features/extensions/  ExtBlocks и изолированный мост
lib/features/image_gen/   провайдеры и интерфейс генерации изображений
lib/features/cloud_sync/  интеграции Dropbox и Google Drive
lib/features/support_assistant/  Astoria Assistant
assets/chat_webview/      рендерер сообщений и ресурсы моста
docs/                     архитектура, инварианты и заметки разработчика
test/                     модульные, UI, интеграционные и регрессионные тесты
```

Перед изменением хранилища, генерации или границ безопасности расширений начни с
[архитектуры](docs/ARCHITECTURE.md) и [инвариантов](docs/INVARIANTS.md).
